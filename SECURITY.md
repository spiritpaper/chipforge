# Security policy

Please report security problems privately, not in public issues:
**[CONTACT: add an email address before publishing]**. Include steps to reproduce
and what an attacker could do.

You'll get a reply within a week. Fixes are released as soon as they're ready, and
reporters are credited unless they'd rather not be.

ChipForge's web app runs entirely in the browser and stores data locally; the most
relevant areas are file parsing (.chipsong, MIDI, audio files, share links) and the
native libraries used by the engine plugins.
